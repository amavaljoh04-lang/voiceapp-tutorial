VoiceApp Developer Tutorial

Guide complet pour creer des applications qui utilisent le serveur VoiceApp. De l'authentification aux messages ephemeres.

API REST WebSocket HTTPS v5.0.0

Introduction

VoiceApp est une API de messagerie vocale ephemere. Les messages vocaux disparaissent apres ecoute (max 2 ecoutes). L'API supporte l'authentification Matrix-style, le temps reel via WebSocket, les stories vocales, les reactions, et plus.

Base URL

https://matrix.voiceapp.be

Documentation interactive

/redocReDoc (documentation lisible)

Architecture

// Architecture du serveur VoiceApp

Client (Flutter/Web/Mobile)
    |
    |--- HTTPS (REST API) ----> Nginx (443) ----> FastAPI (8000)
    |--- WSS (WebSocket) -----> Nginx (443) ----> FastAPI /ws
    |
FastAPI
    |--- PostgreSQL  (donnees utilisateurs, messages, amis)
    |--- Redis       (cache, sessions, pub/sub, presence)
    |--- MinIO/S3    (stockage audio .opus)
Protocole Toutes les communications passent par HTTPS/WSS (TLS 1.2+, HTTP/2). Aucun endpoint HTTP non-securise.

Service API de base

// lib/services/api_service.dart

import 'dart:convert';
import 'package:http/http.dart' as http;
import 'package:shared_preferences/shared_preferences.dart';

class ApiService {
  static const baseUrl = 'https://matrix.voiceapp.be';

  String? _accessToken;
  String? _refreshToken;
  String? _deviceId;

  // Singleton
  static final ApiService _instance = ApiService._internal();
  factory ApiService() => _instance;
  ApiService._internal();

  // Headers avec auth
  Map<String, String> get headers => {
    'Content-Type': 'application/json',
    if (_accessToken != null)
      'Authorization': 'Bearer $_accessToken',
  };

  // Sauvegarder les tokens
  Future<void> saveTokens(String access, String refresh) async {
    _accessToken = access;
    _refreshToken = refresh;
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString('access_token', access);
    await prefs.setString('refresh_token', refresh);
  }

  // Charger les tokens au demarrage
  Future<void> loadTokens() async {
    final prefs = await SharedPreferences.getInstance();
    _accessToken = prefs.getString('access_token');
    _refreshToken = prefs.getString('refresh_token');
    _deviceId = prefs.getString('device_id');
  }

  // Requete GET generique avec auto-refresh
  Future<Map<String, dynamic>> get(String path) async {
    var response = await http.get(
      Uri.parse('$baseUrl$path'),
      headers: headers,
    );

    // Auto-refresh si 401
    if (response.statusCode == 401 && _refreshToken != null) {
      final refreshed = await refreshTokens();
      if (refreshed) {
        response = await http.get(
          Uri.parse('$baseUrl$path'),
          headers: headers,
        );
      }
    }
    return jsonDecode(response.body);
  }

  // Requete POST generique
  Future<Map<String, dynamic>> post(String path, Map body) async {
    var response = await http.post(
      Uri.parse('$baseUrl$path'),
      headers: headers,
      body: jsonEncode(body),
    );

    if (response.statusCode == 401 && _refreshToken != null) {
      final refreshed = await refreshTokens();
      if (refreshed) {
        response = await http.post(
          Uri.parse('$baseUrl$path'),
          headers: headers,
          body: jsonEncode(body),
        );
      }
    }
    return jsonDecode(response.body);
  }
}

Flutter

// lib/services/auth_service.dart

Future<Map<String, dynamic>> register({
  required String username,
  required String email,
  required String password,
  String? displayName,
}) async {
  final api = ApiService();
  final deviceId = await _getOrCreateDeviceId();

  final response = await http.post(
    Uri.parse('${ApiService.baseUrl}/api/v1/auth/register'),
    headers: {'Content-Type': 'application/json'},
    body: jsonEncode({
      'username': username,
      'email': email,
      'password': password,
      'display_name': displayName,
      'device_id': deviceId,
    }),
  );

  if (response.statusCode == 201) {
    final data = jsonDecode(response.body);
    await api.saveTokens(data['access_token'], data['refresh_token']);
    return data;
  }
  throw Exception(jsonDecode(response.body)['detail']);
}

Future<String> _getOrCreateDeviceId() async {
  final prefs = await SharedPreferences.getInstance();
  var id = prefs.getString('device_id');
  if (id == null) {
    id = 'flutter-${DateTime.now().millisecondsSinceEpoch}';
    await prefs.setString('device_id', id);
  }
  return id;
}

Future<Map> login(String login, String password) async {
  final response = await http.post(
    Uri.parse('${ApiService.baseUrl}/api/v1/auth/login'),
    headers: {'Content-Type': 'application/json'},
    body: jsonEncode({
      'login': login,
      'password': password,
      'device_id': await _getOrCreateDeviceId(),
    }),
  );

  final data = jsonDecode(response.body);

  if (response.statusCode == 200) {
    // Connexion reussie
    await ApiService().saveTokens(
      data['access_token'],
      data['refresh_token'],
    );
    return data;
  }

  if (response.statusCode == 202) {
    // 2FA requis - afficher l'ecran de code
    return data; // {"requires_2fa": true, "temp_token": "..."}
  }

  throw Exception(data['detail'] ?? 'Erreur de connexion');
}

Refresh Token

POST /api/v1/auth/refresh

Renouveler le access_token avec le refresh_token

Future<bool> refreshTokens() async {
  final response = await http.post(
    Uri.parse('${ApiService.baseUrl}/api/v1/auth/refresh'),
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer $_accessToken',
    },
    body: jsonEncode({
      'refresh_token': _refreshToken,
      'device_id': _deviceId,
    }),
  );

  if (response.statusCode == 200) {
    final data = jsonDecode(response.body);
    await saveTokens(data['access_token'], data['refresh_token']);
    return true;
  }
  return false; // Redirect to login screen
}

2FA (Authentification a 2 facteurs)

1. Setup TOTP → 2. Scanner QR → 3. Enable avec code → 4. Login + code TOTP

Obtenir le secret TOTP + QR code

POST /api/v1/2fa/enable

Activer la 2FA avec un code valide

Verifier le code 2FA au login (utilise temp_token)

// 1. Demander le setup 2FA

// 4. Au prochain login, si 2FA active, on recoit un temp_token

Flutter - Enregistrer et envoyer

// lib/services/message_service.dart

import 'package:record/record.dart';

class MessageService {
  final _recorder = AudioRecorder();
  final _api = ApiService();

  // Demarrer l'enregistrement
  Future<void> startRecording() async {
    if (await _recorder.hasPermission()) {
      final dir = await getTemporaryDirectory();
      await _recorder.start(
        RecordConfig(encoder: AudioEncoder.aacLc),
        path: '${dir.path}/voice_msg.m4a',
      );
    }
  }

  // Arreter et envoyer
  Future<Map> stopAndSend(List<String> recipientIds) async {
    final path = await _recorder.stop();
    if (path == null) throw Exception('Enregistrement echoue');

    final request = http.MultipartRequest(
      'POST',
      Uri.parse('${ApiService.baseUrl}/api/v1/messages/send'),
    );
    request.headers['Authorization'] = 'Bearer ${_api.accessToken}';
    request.files.add(
      await http.MultipartFile.fromPath('file', path),
    );
    request.fields['recipient_ids'] = jsonEncode(recipientIds);

    final response = await request.send();
    final body = await response.stream.bytesToString();

    if (response.statusCode == 201) {
      return jsonDecode(body);
    }
    throw Exception(jsonDecode(body)['detail']);
  }
}

import 'package:audioplayers/audioplayers.dart';

Future<void> listenToMessage(String messageId) async {
  // 1. Obtenir l'URL pre-signee
  final data = await api.post(
    '/api/v1/messages/$messageId/listen', {},
  );

  final audioUrl = data['audio_url'];
  final remaining = data['remaining_listens'];

  // 2. Jouer l'audio IMMEDIATEMENT (URL expire dans 5 min)
  final player = AudioPlayer();
  await player.play(UrlSource(audioUrl));

  // 3. Afficher le compteur
  if (remaining == 0) {
    // Derniere ecoute ! Le message sera supprime
    showSnackBar('Derniere ecoute - le message va disparaitre');
  } else {
    showSnackBar('Encore $remaining ecoute(s) restante(s)');
  }
}

WebSocket - Connexion

WSS wss://matrix.voiceapp.be/ws?token=<access_token>

Connexion WebSocket pour le temps reel

Pourquoi pas dans l'OpenAPI ? Le WebSocket n'apparait pas dans /openapi.json car le standard OpenAPI ne supporte pas nativement les WebSockets. Le endpoint existe bien a /ws.

Authentification

Deux methodes :

1
Query param (recommande) : wss://matrix.voiceapp.be/ws?token=syt_xxx
2
Premier message : Envoyer {"token": "syt_xxx"} dans les 5 secondes apres connexion

Heartbeat

Le serveur envoie un ping toutes les 30 secondes. Tu dois repondre avec pong dans les 10 secondes, sinon la connexion est fermee.

WebSocket - Integration Flutter

// lib/services/websocket_service.dart

import 'dart:async';
import 'dart:convert';
import 'package:web_socket_channel/web_socket_channel.dart';

class WebSocketService {
  WebSocketChannel? _channel;
  Timer? _reconnectTimer;
  bool _isConnected = false;

  // Callbacks pour l'UI
  Function(String userId, bool isOnline)? onPresence;
  Function(String userId)? onTyping;
  Function(String userId)? onStopTyping;
  Function(String userId, bool isRecording)? onRecording;
  Function(Map<String, dynamic>)? onNewMessage;
  Function(Map<String, dynamic>)? onFriendRequest;
  Function(String messageId, int count)? onListened;

  /// Se connecter au WebSocket
  void connect(String accessToken) {
    _channel = WebSocketChannel.connect(
      Uri.parse('wss://matrix.voiceapp.be/ws?token=$accessToken'),
    );
    _isConnected = true;

    _channel!.stream.listen(
      (data) => _handleMessage(jsonDecode(data)),
      onDone: () {
        _isConnected = false;
        _scheduleReconnect(accessToken);
      },
      onError: (e) {
        _isConnected = false;
        _scheduleReconnect(accessToken);
      },
    );
  }

  /// Gerer les messages recus
  void _handleMessage(Map<String, dynamic> msg) {
    switch (msg['type']) {
      case 'ping':
        _channel?.sink.add(jsonEncode({'type': 'pong'}));
        break;

      case 'presence':
        onPresence?.call(msg['user_id'], msg['is_online']);
        break;

      case 'typing':
        onTyping?.call(msg['user_id']);
        break;

      case 'stop_typing':
        onStopTyping?.call(msg['user_id']);
        break;

      case 'recording':
        onRecording?.call(msg['user_id'], msg['is_recording']);
        break;

      case 'new_message':
        onNewMessage?.call(msg);
        break;

      case 'friend_request':
        onFriendRequest?.call(msg);
        break;

      case 'listened':
        onListened?.call(msg['message_id'], msg['listen_count']);
        break;

      case 'session_replaced':
        // Deconnecte ! Afficher alerte et rediriger au login
        _isConnected = false;
        break;
    }
  }

  /// Envoyer un indicateur "typing"
  void sendTyping(String targetId) {
    _send({'type': 'typing', 'target_id': targetId});
  }

  /// Envoyer "stop_typing"
  void sendStopTyping(String targetId) {
    _send({'type': 'stop_typing', 'target_id': targetId});
  }

  /// Envoyer indicateur "recording"
  void sendRecording(String targetId, bool isRecording) {
    _send({
      'type': 'recording',
      'target_id': targetId,
      'is_recording': isRecording,
    });
  }

  /// Envoyer un accuse de lecture
  void sendReadReceipt(String targetId, String messageId) {
    _send({
      'type': 'read_receipt',
      'target_id': targetId,
      'message_id': messageId,
    });
  }

  void _send(Map<String, dynamic> data) {
    if (_isConnected) {
      _channel?.sink.add(jsonEncode(data));
    }
  }

  void _scheduleReconnect(String token) {
    _reconnectTimer?.cancel();
    _reconnectTimer = Timer(Duration(seconds: 3), () => connect(token));
  }

  void disconnect() {
    _reconnectTimer?.cancel();
    _channel?.sink.close();
    _isConnected = false;
  }
}

Le systeme de recuperation permet de reinitialiser le mot de passe via un code 6 chiffres envoye par email, et de se connecter avec des codes de secours si le 2FA est perdu.

2. Confirmer le reset avec le code

Reinitialiser le mot de passe avec le code recu par email

ParametreTypeDescription

new_passwordstringNouveau mot de passe (8+ chars, maj, min, chiffre)

# Reponse succes :
# {"message": "Mot de passe reinitialise avec succes"}

# Reponse erreur (code invalide/expire) :
# {"detail": "Code ou token invalide ou expire"}
// Flutter - Confirmer le reset avec le code
Future<bool> confirmPasswordReset(String email, String code, String newPassword) async {
  try {
    final response = await http.post(
      Uri.parse('${ApiService.baseUrl}/api/v1/recovery/password-reset/confirm'),
      headers: {'Content-Type': 'application/json'},
      body: jsonEncode({
        'code': code,
        'email': email,
        'new_password': newPassword,
      }),
    );
    if (response.statusCode == 200) {
      // Succes ! Rediriger vers l'ecran de login
      return true;
    } else {
      // Code invalide ou expire
      final error = jsonDecode(response.body);
      throw Exception(error['detail'] ?? 'Erreur inconnue');
    }
  } catch (e) {
    rethrow;
  }
}

class PasswordResetCodeScreen extends StatefulWidget {
  final String email;
  const PasswordResetCodeScreen({required this.email});

  @override
  State<PasswordResetCodeScreen> createState() => _PasswordResetCodeScreenState();

class _PasswordResetCodeScreenState extends State<PasswordResetCodeScreen> {
  final _codeController = TextEditingController();
  final _passwordController = TextEditingController();
  bool _isLoading = false;

  Future<void> _submit() async {

        _codeController.text.trim(),
        _passwordController.text,

        SnackBar(content: Text('Code invalide ou expire')),
      );
    } finally {
      setState(() => _isLoading = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Reinitialisation')),
      body: Padding(
        padding: EdgeInsets.all(24),
        child: Column(
          children: [
            Text('Un code 6 chiffres a ete envoye a ${widget.email}'),
            SizedBox(height: 24),
            TextField(
              controller: _codeController,
              keyboardType: TextInputType.number,
              maxLength: 6,
              decoration: InputDecoration(labelText: 'Code 6 chiffres'),
            ),
            SizedBox(height: 16),
            TextField(
              controller: _passwordController,
              obscureText: true,
              decoration: InputDecoration(labelText: 'Nouveau mot de passe'),

Securite : Apres un reset reussi, toutes les sessions actives sont revoquees. L'utilisateur doit se reconnecter sur tous ses appareils. Le rate limit est de 3 tentatives/minute pour eviter le brute-force du code.

3. Flow complet de recuperation dans l'app

Etape 1 : Ecran "Mot de passe oublie ?" → L'utilisateur entre son email
Etape 2 : Appel POST /recovery/password-reset/request → Afficher "Code envoye"
Etape 3 : Ecran de saisie du code 6 chiffres + nouveau mot de passe
Etape 4 : Appel POST /recovery/password-reset/confirm avec {code, email, new_password}
Etape 5 : Si succes → Rediriger vers l'ecran de login avec message "Mot de passe reinitialise"
Etape 6 : Si erreur → Afficher "Code invalide ou expire" avec option de renvoyer

// Flutter - Login avec code de secours
Future<Map<String, dynamic>> loginWithRecoveryCode(
  String login, String recoveryCode, {String? deviceId}
) async {
  final response = await http.post(
    Uri.parse('${ApiService.baseUrl}/api/v1/recovery/codes/login'),
    headers: {'Content-Type': 'application/json'},
    body: jsonEncode({
      'login': login,
      'recovery_code': recoveryCode,
      if (deviceId != null) 'device_id': deviceId,
    }),
  );
  if (response.statusCode == 200) {
    final data = jsonDecode(response.body);
    await ApiService().saveTokens(data['access_token'], data['refresh_token']);
    return data;
  }
  throw Exception('Code de recuperation invalide');
}
Important : Chaque code de secours est utilisable une seule fois. Apres utilisation, il est marque comme "used". Conseillez aux utilisateurs de conserver ces codes en lieu sur et de les regenerer regulierement.

Flutter - Gestion globale des erreurs

class ApiException implements Exception {
  final int statusCode;
  final String message;

  ApiException(this.statusCode, this.message);

  bool get isUnauthorized => statusCode == 401;
  bool get isRateLimited => statusCode == 429;
  bool get is2FARequired => statusCode == 202;

  @override
  String toString() => 'ApiException($statusCode): $message';
}

// Utilisation dans un try/catch
try {
  await authService.login(email, password);
} on ApiException catch (e) {
  if (e.is2FARequired) {
    Navigator.push(context, TwoFactorScreen(tempToken: e.message));
  } else if (e.isRateLimited) {
    showSnackBar('Trop de tentatives, reessaie dans 1 minute');
  } else {
    showSnackBar(e.message);
  }
}
